# [5. Longest Palindromic Substring](https://leetcode.com/problems/longest-palindromic-substring)

`Medium` level 

Given a string `s`, return *the longest **palindromic substring***<sup>1</sup> in `s`.  

**1.** A **substring** is a contiguous **non-empty** sequence of characters within a string.  

<br />

**Example 1:**
<pre>
<strong>Input:</strong> s = "babad"
<strong>Output:</strong> "bab"
<strong>Explanation:</strong> "aba" is also a valid answer.
</pre>

**Example 2:**
<pre>
<strong>Input:</strong> s = "cbbd"
<strong>Output:</strong> "bb"
</pre>

<br />

** Constraints:**

* <code>1 <= s.length <= 1000</code>
* <code>s</code> consist of only digits and English letters.
